安全与恢复规则

正常使用

  • Key 在 Webview 中永远只显示掩码
  • 同步密码首次输入后可保存在本机 SecretStorage
  • 新增、编辑或删除 Key 后自动更新加密包
  • 关闭 Settings Sync 不影响本机渠道

必须明确的限制

  • 忘记同步密码无法解密云端密钥包
  • 重置同步密码需要在仍能解锁的设备上完成
  • 多设备同时修改时进行版本检查，冲突时要求用户选择
  • 该功能必须由用户明确开启，不默认上传密文
生成逻辑边界

解锁只负责把对应 Key 放回 SecretStorage。生成提交信息时仍按现有顺序读取 diff、默认 Prompt 和上下文，再使用当前渠道调用 OpenAI 或 Anthropic；不会改写原 Prompt 或提交格式。
