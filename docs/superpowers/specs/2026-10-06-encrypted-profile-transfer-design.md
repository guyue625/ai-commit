# 加密渠道配置导入导出

用户已选择使用密码加密文件迁移渠道配置和 API Key，导入保留本机配置。

- 替换配置中心的“加密 Key 同步”为“导入 / 导出”。导出全部 OpenAI / Anthropic 渠道参数及本机 Key，不迁移通用设置、Prompt 或连接测试历史。
- 文件整体采用 scrypt + AES-256-GCM 加密，包含格式版本；密码仅用于本次操作，不保存。扩展宿主通过 VS Code 文件对话框读写文件，Webview 不接收完整 Key 或文件内容。
- 导入完整解密校验后再写入。按渠道 ID 或同服务商同名判断冲突，跳过已有渠道；不会覆盖、删除或切换当前渠道。新设备导入后手动测试并启用渠道。
- 所有导入 Key 先写入并回读验证，再一次性提交渠道目录。失败回滚新增 Key 和目录；文件损坏、密码错误、版本不支持均不修改配置。
- 取消文件对话框不显示成功提示。缺少本机 Key 时阻止导出并提示补齐，避免生成误以为完整的备份。
- 取消 Settings Sync 注册，将旧目录及备份迁移到新的本机存储键，防止旧版同步覆盖本机数据。保留旧密钥包的手动恢复能力，只填补缺失 Key，不覆盖已有 Key，不恢复自动同步。
- 验证加密往返、篡改、密码错误、参数校验、冲突跳过、缺失 Key、写入失败回滚、取消对话框、旧数据迁移，以及现有单测、lint、生产构建和扩展宿主测试。
